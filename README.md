## How to Play & Controls

Master the **Mid-Air Dash** to launch yourself sky-high off balloons!

<div align="center">

| Input | Action | Pro Tip 💡 |
| :---: | :---: | :--- |
| <kbd>A</kbd> / <kbd>D</kbd> | **Move Left / Right** | Steer in mid-air to line up your next landing |
| <kbd>Space</kbd> | **Jump** | Jump from the starting ground to reach the first balloon |
| <kbd>🖱️ Left Click</kbd> | **Dash Down** | Click while in the air to slam down onto a balloon and **BOUNCE EVEN HIGHER!** 🚀 |

</div>

---

## 🌟 Game Features

- 🎈 **Dynamic Balloon Patterns**: Every round randomly picks from multiple hand-crafted balloon layouts.
- ⚡ **High-Speed Dash-Bounce Mechanic**: Chain downward dashes into super-bounces to clear huge vertical gaps in seconds.
- 🎨 **Custom Sprites & Parallax Sky**: Animated frog state machine (`Idle`, `Run`, `Up`, `Flip`, `Fall`, `Dash`) set against a multi-layered parallax background.
- 💣 **10-Second Microgame Rush**: Beat the ticking bomb timer to claim victory!
